# セフィリア QoL (Sephiria QoL) モッド

**セフィリア QoL** は、セフィリア本体では対応していない各種の **便利機能・難易度調整・その他チート寄りの機能** をまとめた総合モッドです。シングルプレイ、あるいは **同じ QoL 利用者どうしのマルチプレイ** を前提に開発しています。

すべての機能を切れば、原作（バニラ）とまったく同じ挙動になるよう作ってあります。

> **マルチプレイの注意**
> QoL モッドにはチート寄りの機能が含まれるため、無分別にマルチで使うとチート扱いされることがあります。そのため機能をすべて入れた状態では **バニラ利用者とのマルチプレイが既定で制限** されます。
> * **自分がホストのとき:** 部屋名に `[QoL]` が付き、バニラ利用者が入ってくると自動で退室させます。
> * **自分がゲストのとき:** バニラホストの部屋に入ると10秒後に自動で退室します。
> * バニラ利用者と一緒に遊びたい場合は、下の **便利機能のみ** または **便利機能＋ホスト機能** を使ってください。制限はかかりません。

---

## 導入方法

1. ダウンロードした書庫の中身を、セフィリアのインストールフォルダ内の AddOns フォルダに入れます。
2. パスは次のようになります:
   `.../Sephiria/AddOns/SephiriaQoL/SephiriaQol.dll`
3. **注意:** `Libs` フォルダも必ず同じ場所に一緒に置かないと正しく動きません！

別途のローダーを入れる必要はありません。ゲーム内蔵のアドオンローダーがそのまま読み込みます。

## 設定の開き方

ゲーム中に `ESC` を押して **一時停止メニュー** を開くと、**[QoL 設定] · [QoL 情報] · [QoL 探索記録]** の三行が増えているのが分かります。

<img width="739" height="804" alt="image" src="https://github.com/user-attachments/assets/0f6b618a-b376-4010-a474-622e3dad7902" />

設定ウィンドウは `一般 / 敵まわりの設定 / 探索まわりの設定 / 難易度緩和 / 画面表示` の五つのタブに分かれていて、`Q` `E`（パッドは LB · RB）でタブを移動します。

* **スライダー:** 倍率のように段階が多い行にはスライダーが付いています。
* **数値の直接入力:** スライダーの付いた行なら、右側の数値をマウスで押して直接打ち込めます。画面に見えているとおりに打てば大丈夫です。（`1.5` → x1.5、`150` → 150%、`2000` → +2000リーフ）
  * 倍率の行は表にない値も 0.1 刻みで受け付けます。マス・人・回で数える行は最も近い段階に寄ります。
* **探索中はほとんど隠れます:** 難易度や報酬に関わる行は探索が始まると消え、ロビーに戻ると再び出てきます。探索の途中で難易度を変えるのは事実上のチートだからです。

## 一般設定と機能

<img width="850" height="94" alt="image" src="https://github.com/user-attachments/assets/4f18a54b-0f95-4559-b1b4-ba62daeef153" />

### QoL 機能の動作モード
遊び方に合わせて 4 段階から選べます。分ける基準は難易度ではなく、**その機能がどこで判定されるか** です。

* **切る（原作と同じ）:** バニラとまったく同じ状態になります。
* **便利機能のみ:** 自分の画面と自分の入力で始まってそこで終わるものだけを残します。外に出るものが何もないので、部屋名の表示もチャット通知もモッド確認の挨拶もありません。外から見るとモッドを入れていない人と区別が付きません。
* **便利機能＋ホスト機能:** 上のものに加えて、**サーバー側だけで判定されるもの** まで入れます。ホストひとりがモッドを持っていれば済む機能なので、モッドのないゲストにもそのまま適用されます。バニラ利用者とのマルチ制限はなく、代わりに探索開始時にチャットで QoL 機能が入っている旨を知らせます。
* **入れる（すべて）:** すべての機能を有効にします。バニラ利用者とのマルチプレイは制限されます。

`/qol on | host | solo | off` でも切り替えられます。この値だけは `/qol reset` やプリセットの影響を受けません。

 <img width="850" height="59" alt="image" src="https://github.com/user-attachments/assets/479e0a73-7630-4c8c-8a60-09ca66e0f163" />

#### 「便利機能のみ」で残る項目

**〈一般〉**
* 長押しで魔法を連続詠唱
* 長押しで特殊攻撃を連続発動
* プリセット枠を100個に拡張
* 町に才能の鏡を置く

**〈探索まわり〉**
* 再抽選ボタンの長押しをなくす
* マルチプレイの最大人数（自分の上限が開いていないと拡張された部屋に入れないため、ここに置いてあります。入れてもバニラの部屋が広がるわけではありません。）

**〈画面表示〉**
* タブ全部。探索記録も含みます。

設定行ではない機能（図鑑の名前検索、`ESC` メニューの QoL 情報）は、この段階でもそのまま使えます。

#### 「便利機能＋ホスト機能」で追加される項目
> 以下はすべて **ホスト基準** で適用されます。自分がホストならモッドのないゲストにもかかり、自分がゲストなら値を変えてもその探索には影響しません。

**〈一般〉**
* QoL プリセット

**〈敵まわり〉**
* 敵の出現・体力・与ダメージ・行動速度の四つの倍率すべて（適用範囲を含む）
* 血の祭典を緩和
* 中ボスにも出現倍率を適用

**〈探索まわり〉**
* レベルアップごとに所持枠を付与
* リーフ・経験値の獲得倍率
* 開始時のリーフ追加、開始時のサイコロを追加
* インベントリの横の数
* 最初の選択肢に金床を保証、追加の金床
* 幸運のメダルの効果を共有、交渉力・リーフ・経験値の獲得量を共有
* ポーション取得を共有
* 商人の体力設定、友好NPCの設定
* 商人の所持枠／経験値販売を確定、神秘の壺の出現を確定

**〈難易度緩和〉**
* エンチャント回数を固定
* 金床の選択肢を増やす
* 戦闘中にステータス／所持品を開く

ここから外れるのは **ゲストの端末で判定されて盤面を変える機能** です。リーフとサイコロの受け渡し、願いの泉まわり、図鑑の除外、固有制限の解除、チート類、尖塔の再抽選、再抽選制限、ゲーム速度、蘇生速度、レベル上限の解除、奇跡のリロール無料、そのほかの難易度緩和がこれにあたります。ホストだけが入れると、むしろモッドのないゲスト側が壊れるからです。

### プリセット機能
QoL モッドは設定項目が多いため、製作者が推奨する既定のプリセット（やさしい／ふつう／むずかしい／非常にむずかしい）を用意しています。任意に設定を変えると「カスタム」状態になります。

<img width="850" height="137" alt="image" src="https://github.com/user-attachments/assets/37e9cec8-405e-4832-958e-6664d8a4099d" />

**個人プリセットの保存と読み込み（チャットコマンド）**
* 保存: `/qol save 1~9`
* 読み込み: `/qol load 1~9`
* 一覧: `/qol list`

### 設定をコードでやり取りする
設定ファイルをまるごと渡す必要はありません。

* `/qol export` で今の設定を一行の文字列にしてクリップボードに入れます。
* 受け取った側はそれをコピーして `/qol import` と打つだけです。`/qol import [コード]` と直接書いても構いません。

出ていくのは今使っている設定ひと組だけです。九つの枠は含まれず、**画面表示・個人の入力まわり・図鑑の除外はコードに載りませんし、上書きもされません。**

### その他の便利機能
* **魔法／特殊攻撃の自動発動:** 魔法や発動型アーティファクトを押しっぱなしにすると、クールタイムごとに自動で発動します。（即発型の特殊攻撃も含みます）
* **図鑑の検索機能:** 図鑑で項目を名前から検索できます。

<img width="584" height="81" alt="image" src="https://github.com/user-attachments/assets/7cc5a8d5-5999-4c09-9007-d86bc5fb9b58" />

* **町に才能の鏡を置く:** シングルプレイの町のダンジョン入口前に才能の鏡を立てます。才能を選ぶためだけにマルチの部屋を開いて閉じる手間がなくなります。
* **QoL 情報の確認:** `ESC` の一時停止メニューから、今の探索に適用されている QoL 設定をその場で確認できます。ゲストのときはホストから実際に受け取った値だけを表示します。

## 敵まわりの設定

<img width="849" height="282" alt="image" src="https://github.com/user-attachments/assets/dcedbba9-b07d-41c2-991e-32e67217ba2a" />

出現・体力・与ダメージ・行動速度の四つは、どれも同じ仕組みです。倍率の行の下に **適用範囲** の行が一つずつ付いていて、その倍率をどこまで細かく分けるかをここで決めます。

* **全体で一つ:** 一つの値がすべてにかかります。
* **階層別:** 1〜6階を別々に決めます。
* **種類別:** 雑魚／中ボス／ボスを別々に決めます。
* **階層別＋種類別:** 階ごとに三種類を別々に決めます。

範囲を行き来しても、それぞれの範囲の値は消えずに残ります。

* **敵の出現倍率:** 敵の湧く数を倍率で設定します。`1/4倍` `1/2倍` から `x100` まであります。（コマンド: `/s 数値` または `/s 数値 階`）
* **敵の体力倍率:** 敵の体力を調整します。ハクスラ寄りの遊び方のために `出現倍率のぶん下げる` と `0.1倍`〜`0.9倍` も用意しています。（コマンド: `/h 数値` または `/h 数値 階`）
* **敵の与ダメージ倍率:** `0.1倍` から `x100`、さらに `即死モード` まで。
* **敵の行動速度:** 行動のクールダウンを詰めて攻撃頻度を上げます。`0.5倍`〜`3倍`。
* **中ボスへの倍率適用:** 中ボスも出現倍率のぶんだけ複数出てきます。体力のほうは元の数値が大きく、倍率をそのままかけると討伐が長くなりすぎるので、種類別の範囲で中ボスだけ下げるか `出現倍率のぶん割る` で釣り合いを取るのがおすすめです。
* **血の祭典を緩和:** 敵の体力倍率が入っていても、吸血はモンスターの「素の最大体力」だけを基準に計算させます。

`x25` 以上は数値が赤く表示され、適用時に処理落ちの警告が出ます。コマンドなら999倍まで指定できます。

## 探索まわりの設定

* **ゲーム速度:** ゲーム速度を 0.5倍〜2倍 で調整します。マルチでは **ホストの値を全員がそのまま使います。**（全員がモッドを持つ「入れる（すべて）」の部屋でのみ動作）
* **インベントリの横の数:** 既定で6マスの持ち物の横幅を1〜10マスに変更します。
* **サファイア再抽選まわりの改編:**
  > ローグライクの本質を損なう単純な資源の周回稼ぎを減らすための設定です。
  > 再抽選の価格を0に固定しつつ、無限に引いて確定入手するのを防ぐため **再抽選の回数に制限** を設けられます。（チート寄りにも縛り寄りにも合わせられます）
* **再抽選ボタンの長押しをなくす:** ボタンを押しっぱなしにしなくてもすぐ引けます。
* **レベル上限を解除:** 最大レベルを1000あたりまで引き上げ、実質的に上限をなくします。
* **レベルアップごとに所持枠を付与:** nレベルごとに持ち物のマスを1つ渡します。（高難度の探索を和らげる用途）
* **蘇生速度の倍率:** マルチでの味方の蘇生速度を 0.1倍〜10倍 で調整します。
* **リーフ・経験値の獲得倍率:** x0.1〜x20.0 を 0.1 刻みで調整します。

### マルチプレイ向けの機能
* **資源の受け渡し:** チャットでリーフやサイコロを他人に渡します。（ニックネームの代わりに番号も使えます）
  * リーフ: `/giveleaf [名前/番号] [数]`（短縮: `/gl`）
  * サイコロ: `/givedice [名前/番号] [数]`（短縮: `/gd`）
* **開始アイテムの受け渡し:** 願いの泉や才能などで得た開始アイテムを落として、他の人が拾えるようにします。
* **幸運のメダルとステータスの共有:**
  * 幸運のメダルの効果をパーティで共有します。
  * 交渉力、リーフ・経験値の獲得量をパーティ内の最高値で共有します。
* **分配機能（稼ぎ特化構成の調整用）:** 資源獲得に全振りした構成が強すぎるのを抑えるため、リーフ・経験値の獲得量を **パーティ人数で割って分配** します。
* **ポーション取得を共有:** フィールドの箱から出たポーションを、早い者勝ちではなく全員に1つずつ渡します。
* **人数上限の拡張:** マルチの人数を最大16人まで増やします。（UI が重なることがあります。ゲームが4人を基準に組んでいる経験値の分配がずれるので、大きく増やすときは経験値倍率で釣り合いを取るほうが無難です。）

### 運・オブジェクトの補正
* **最初の部屋に金床を保証:** 1階または2階の最初の部屋に必ず金床を出します。
* **追加の金床:** 階の開始時に金床を1〜2個ぶん増やして置きます。
* **尖塔の再抽選:** サイコロを1つ使って尖塔の報酬を引き直します。
* **願いの泉の制限解除:** 願いの泉で結束アーティファクトと怪しい商人の品物を選べるようにします。
* **願いの泉で同じ物を複数:** 同じアイテムを複数入れられるようにします。**左クリックが入れる、右クリックが取り出す** で、アイコンの左上に個数が出ます。容量とコストはゲームの計算そのままなので、二つ入れればコストも二倍です。固有アーティファクトは一つまでです。（パッドはアイテム回転ボタンが取り出しです）
* **図鑑の除外機能:** 図鑑でホイールクリックして、アーティファクト／石板／武器／奇跡を出現しないようにします。探索中は全員がホストの一覧に従います。（コマンド: `/qol ban all`、`/qol ban off`）

<img width="850" height="248" alt="image" src="https://github.com/user-attachments/assets/7d9891b4-a796-4fde-923f-e91feb07c15f" />

* **特殊オブジェクトの保証:** 各階のボス撃破時に、尖塔・怪しい商人・亜空間の店・献血イベントを強制的に生成します。（6階はボスを倒すとそのまま終幕なので用意していません。）

<img width="850" height="599" alt="image" src="https://github.com/user-attachments/assets/7cba1c05-091c-4035-aaab-5808b0694c6d" />

* **商人部屋の設置物を確定:** 商人のそばにある経験値の樽・所持枠の玉・神秘の壺は、それぞれ確率を引いて自分から消えます。これをそれぞれ必ず出るようにします。
* **商人の体力設定／友好NPCの設定:** 自動攻撃の構成でうっかり商人を殴って敵対させてしまうことと、友好NPCをわざと倒して資源を稼ぐことを、塞いだり開いたりします。商人は `無敵` か `体力を1にする`、友好NPCは `マップから除去` か `体力を1にする` から選びます。

## 難易度緩和（チート機能）

明らかにゲームを易しくする設定です。

* **マップを全て開く:** 隠し部屋や出口を含めた地図を即座に開き、高速移動を有効にします。
* **報酬の選択肢と箱の追加:** アーティファクト、所持枠、願いの泉、フルーツ串、才能ポイント、開始リーフ、サイコロなどの数を増やします。（ボス撃破時に報酬箱の倍率が適用されます）
* **金床の選択肢を増やす:** 金床で選べる強化をすべて表示します。
* **店の緩和:** 商人の販売品目数と、再抽選で増える品目数を増やします。
* **エンチャント回数を固定:** エンチャント部屋で出る回数を1〜10の間で固定します。
* **奇跡のリロール無料:** サイコロが無くても奇跡を引き直し続けられます。
* **戦闘中にステータス／所持品を開く:** 戦闘中でもステータス画面と持ち物を開けます。時間は流れ続けるので、開いたまま攻撃を受けます。
* **チンターマニの刻印:** チンターマニは本来、死亡時に一度だけ蘇生させ、そのマスに `+3` レベルを残して消えます。この設定を入れると、鞄の中のチンターマニを右クリック長押しして石板の刻印と同じゲージを溜め、後半だけを先に受け取れます。残ったレベルは、あとでそのマスに置くアーティファクトにもそのまま乗ります。
* **ハードモード報酬の解放緩和:** 解放が進んでいない人が高段階（60）をクリアすると、50レベルぶんまで一度に解放されます。
* **固有制限を解除:** 固有効果を持つアーティファクトを重複して入手し、効果を重ねられるようにします。（一部は適用されません）
* **サファイア／サイコロのチート:**
  * ホストは、その部屋でゲストの資源チートを許可するかどうかを決められます。
  * 有効にするとサファイアが 999,999個、サイコロが 999個 に固定されます。
  * `/qol sapphire reset` でサファイアを0個にできます。

  つまりこの二つを使うと、

  「自分の部屋ではチート禁止」
  「自分の部屋ではチート許可だが自分は使わない」
  「自分の部屋ではチート許可で自分も使う」 はできますが、

  「自分の部屋で自分は使うがお前は使うな」 はできません。

## 画面表示

* **パーティ状況ウィンドウ:** 各員の累計ダメージ、ダメージ占有率(%)、DPS、所持資源（リーフ／サイコロ／サファイア）、コンボ TOP 3 を表示します。項目は一つずつ切り替えられ、位置は `右側` か `カスタム`（`Alt + ドラッグ` で移動）から選びます。
* **画面の拡大率:** ゲーム画面を 10%〜200% の間で縮小・拡大します。
* **色覚補助モード:** ゲーム本体の設定とは別に「インベントリの色覚補助モード」と「敵の攻撃予告の色覚補助モード」を個別に入れられます。
  * **コマンド（敵の攻撃予告の色を変える）:**
    * `/qol colorblind <r> <g> <b>`（好きな RGB 値に変更）
    * `/qol colorblind reset`（既定の水色に戻す）
    * `/qol colorblind`（今の RGB 値を確認）
* **落ちた経験値・リーフの表示:** 床に落ちた経験値とリーフを薄く描きます（50% ／ 25% ／ 見えないように）。画面が混み合うと敵の弾と紛らわしいためで、描画が変わるだけで取得には影響しません。
* **ボスの体力を数値で表示:** ボスと中ボスの体力バーに数値を添えます。
* **ボスの狙う相手を表示:** ボスと、狙われている側に同じ色の枠を描きます。
* **持ち物のマスにエンチャント回数を表示:** アイテムのマスの右下に `★2` のように何回エンチャントしたかを書きます。本来はマスごとにツールチップを出さないと分かりません。（既定で入っています）
* **隠し部屋があれば知らせる:** 地図に隠し部屋があるとき、階に入った時点で一行で知らせます。
* **他人のピンを表示しない:** 他の人が打ったピンのアイコンと音をすぐに遮ります。
* **チャットログの有効化:** チャット欄を開いた状態でログの上にマウスを置きホイールを回すと、直近200行までさかのぼれます。
* **アイテム取得通知のハイライト:** 取得ログのアイテム名をレアリティの色で塗ります。その場で結束が成立するアーティファクトは、金色から緑に移る色で別に表示します。

### 探索記録
ゲームには終わった探索を振り返る手段がありません。リザルト画面を閉じた瞬間に、その探索の鞄もダメージも丸ごと消えます。そこでリザルト画面が開いた時点で **直近30回** をファイルに書き写します。

`ESC` → `QoL 探索記録`、または `/qol runs` で見ます。`オフ ／ 自分のぶんだけ ／ パーティ全員` から選び、既定は `自分のぶんだけ` です。

* 結果、最後の場所、経過時間、レベル、武器、奇跡、与えた／受けたダメージ、主なダメージ源が残ります。
* `Tab` で **鞄** のページに移ると、その探索が終わったときの持ち物を配置そのままで見られます。もう一度押すと **統計** のページです。
* `Enter` を押すと **ゲームのリザルト画面そのもの** が開き直します。そこから `[ダメージ]` でその探索のダメージ画面まで見られます。
* 操作はキーボードが `← →` 回、`↑ ↓` 人、`Tab` ページ、`Enter` 詳細、`ESC` 閉じる。パッドは方向キー・`Y`・`A`・`B` です。
* 記録は自分の端末のファイル一つに書かれるだけで、通信は行いません。`/qol runs clear` で消せます。（元に戻せません）

## チャットコマンド

```
/help                              コマンド案内

/s <倍率> [階]                     敵の出現倍率   (/spawnrate)
/h <倍率> [階]                     敵の体力倍率   (/hprate)

/gl <名前|番号> <数>                リーフを渡す      (/giveleaf)
/gd <名前|番号> <数>                サイコロを渡す    (/givedice)
/cheat s | /cheat d                サファイア・サイコロのチート状態

/qol on | host | solo | off        すべて / 便利+ホスト / 便利のみ / 切る
/qol reset                         すべての設定を原作どおりに戻す
/qol load easy|normal|hard|expert  難易度プリセットの適用
/qol save <1~9> | load <1~9>       枠へ保存 / 枠から読み込み
/qol list                          プリセットと枠の状態を見る
/qol export | import [コード]       設定をコードでやり取り
/qol ban all | off                 全アーティファクトを除外 / 戻す
/qol runs [clear]                  探索記録を見る / 消す
/qol speed                         今かかっているゲーム速度とその出どころ
/qol sapphire reset                サファイアを0個に
/qol colorblind <r> <g> <b>        攻撃予告の強調色を決める
```

倍率コマンドに階を書くと階層別が自動で入り、階を書かなければ全体の値が使われます。値を省いてコマンドだけ打つと、今の設定を表示します。

設定を変えるコマンドは **ロビーでのみ** 通ります。読むだけの `/qol list` `/qol export` `/qol runs` `/qol speed` は探索中でも使えます。
