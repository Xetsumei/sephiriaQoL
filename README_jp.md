# セフィリア QoL (Sephiria QoL) MOD

**セフィリア QoL** は、セフィリア本編では標準対応していない各種 **便利機能、難易度調整機能、その他のチート系機能** をまとめた総合 MOD です。この MOD は、シングルプレイまたは **同じ QoL ユーザー同士でのマルチプレイ** を前提に開発されています。

すべての機能をオフにすると、バニラ（無改造）状態と完全に同じ動作になるよう設計されています。

> **マルチプレイに関する注意事項**
> QoL MOD にはチート系機能が含まれているため、不特定の相手とのマルチプレイではチートと見なされる可能性があります。そのため、**バニラ（無改造）ユーザーとのマルチプレイは基本的に制限** されます。
> * **自分がホストの場合：** 部屋名の先頭に `[QoL]` が付き、バニラユーザーが入室すると自動的にキックします。
> * **自分がゲストの場合：** バニラホストの部屋に入ると、チャットで `[MOD] セフィリア QoL を適用中です。` と通知し、QoL 機能が「オン」に設定されている場合は自動的に退室します。（ホストの設定に従います。）

---

## インストール方法

1. ダウンロードした圧縮ファイルの中身を、セフィリアのインストールフォルダー内にある AddOns フォルダーへ入れます。
2. パスは次のようになっている必要があります：
   `.../Sephiria/AddOns/SephiriaQoL/SephiriaQol.dll`
3. **注意：** 正常に動作させるには、`Libs` フォルダーも必ず同じパス内に置いてください！

## 一般設定と機能

### QoL MOD の有効状態
プレイヤーの好みに応じて、MOD の動作を3段階から選べます。

* **QoL 機能を切る：** バニラ状態と完全に同じになります。
* **QoL 機能を入れる：** すべての機能を有効にします。（バニラユーザーとのマルチプレイは制限されます。）
* **QoL 機能を便利機能のみにする：** チート系機能を除き、純粋な便利機能だけを使用します。このモードではバニラユーザーとのマルチプレイ制限がなくなる代わりに、探索開始時に QoL 機能がオンであることをチャットで通知します。

 <img width="850" height="59" alt="image" src="https://github.com/user-attachments/assets/479e0a73-7630-4c8c-8a60-09ca66e0f163" />

#### 便利機能のみで使用できるオプション一覧
> ★ 印は **ホスト専用** 機能です。自分がホストの場合にのみ動作し、MOD を導入していないゲストにも適用されます。自分がゲストの場合は、倍率を調整してもホストには影響しません。

**<一般>**
* 長押しで魔法を連続詠唱
* 長押しで特殊攻撃を連続発動
* プリセット枠を100個に拡張

**<敵関連>**
* ★ 敵の出現倍率 / 階層別設定
* ★ 敵の体力倍率 / 階層別設定 / 種類別設定
* ★ 血の祭典を緩和
* ★ 中ボスにも出現倍率を適用
* ★ 敵のダメージ倍率設定
* ★ 敵の行動速度設定

**<探索関連>**
* 再抽選ボタンの長押しをなくす
* ★ レベルアップごとに所持枠を付与
* ★ リーフ / 経験値の獲得倍率
* ★ ゲーム開始時にリーフを付与
* ★ 幸運のメダルの効果を共有（ゲストはゴールドのみ獲得）
* ★ 交渉力 / リーフ / 経験値獲得量をパーティ最高値で共有
* ★ ポーション取得を共有
* ★ マルチプレイの最大人数
* 隠し部屋があれば知らせる
* ★ 最初の選択肢に金床を保証

**<難易度緩和>**
* ★ エンチャント回数を固定

**<画面表示>**
* パーティ状況ウィンドウ関連の設定
* 他人のピンを表示しない

### プリセット機能
QoL MOD には設定項目が多いため、制作者推奨の基本プリセット（やさしい/ふつう/むずかしい/非常にむずかしい）を用意しています。設定を任意に変更すると「カスタム」状態になります。

<img width="850" height="137" alt="image" src="https://github.com/user-attachments/assets/37e9cec8-405e-4832-958e-6664d8a4099d" />

**個人プリセットの保存と読み込み（チャットコマンド）**
* 保存：`/qol save 1~9`
* 読み込み：`/qol load 1~9`

### その他の便利機能
* **魔法/特殊攻撃の自動発動：** 魔法や発動型アーティファクトを長押ししていると、クールダウンが終わるたびに自動発動します。（即時発動型の特殊攻撃を含む）
* **ジャーナル検索機能：** ジャーナル内の項目を名前で検索できます。

* **QoL 情報の確認：** `ESC` のポーズメニューから、現在の探索に適用されている QoL オプション情報をリアルタイムで確認できます。

## 敵関連の設定

<img width="849" height="282" alt="image" src="https://github.com/user-attachments/assets/dcedbba9-b07d-41c2-991e-32e67217ba2a" />

* **敵の出現倍率：** 敵の出現数を倍率で設定します。（コマンド：`/spawnrate 数値` または `/s 数値`）
* **敵の出現倍率 — 階層別：** 1~6階の出現倍率を階ごとに個別設定します。（コマンド：`/s 数値 階層`）
* **敵の体力倍率：** 敵の体力を増やします。ハック＆スラッシュ風のプレイ向けに、「出現倍率に応じて体力を下げる」「1/4倍」「1/2倍」のオプションも用意しています。
* **血の祭典を緩和：** 敵の体力倍率がオンになっていても、モンスターの「基本最大体力」のみを基準に吸血するようにします。
* **中ボスへの倍率適用：**
  * **出現倍率：** 中ボスも出現倍率に応じて複数体登場します。
  * **体力倍率：** 中ボスは元々体力が多いため、倍率をそのまま適用すると倒すまでに時間がかかりすぎます。これを防ぐため、追加体力を1/2、1/4に分割するか、「出現倍率で割る」ことでバランスを調整できます。
* **敵のダメージ倍率 / 行動速度：** 敵のダメージ倍率を調整し、行動パターンのクールダウンを短縮して攻撃頻度を上げます。

## 探索関連の設定

* **ゲーム速度：** ゲーム速度を0.5倍 ~ 2倍に調整します。（ラグ防止のための制限あり、マルチプレイには適用されません。）
* **インベントリの横の数：** 標準で6マスのインベントリ幅を1~10マスに変更します。（テスト機能）
* **サファイア再抽選システムの刷新：**
  > ローグライクの本質を損なう、単純な通貨の反復稼ぎ（作業）を減らすためのオプションです。
  > 再抽選価格を0に固定する一方、無限に確定入手できないよう **再抽選回数に上限** を設定できます。（チートプレイにも制限プレイにも、好みに合わせて設定可能）
* **レベル上限を解除：** 最大レベルを約1000レベル前後まで引き上げ、実質的に上限をなくします。
* **レベルアップごとに所持枠を付与：** nレベルごとにインベントリ枠を1マスずつ付与します。（高難易度探索の緩和用）
* **蘇生速度の倍率：** マルチプレイ時の仲間の蘇生速度を0.1倍 ~ 10倍まで調整します。

### マルチプレイ向け機能
* **通貨の受け渡し機能：** チャットでリーフやサイコロを他のプレイヤーに渡せます。（ニックネームの代わりにインデックス番号も使用可能）
  * リーフを渡す：`/giveleaf [ニックネーム/インデックス] [数値]`（短縮形：`/gl`）
  * サイコロを渡す：`/givedice [ニックネーム/インデックス] [数値]`（短縮形：`/gd`）
* **開始アイテムの受け渡し：** 願いの泉や才能などで手に入れた開始アイテムをドロップし、他のプレイヤーが拾えるようにします。
* **幸運のメダル＆ステータス共有：**
  * 幸運のメダルの効果をパーティメンバーと共有します。
  * 交渉力、リーフ/経験値獲得量をパーティ内の最高値で共有します。
* **分配機能（稼ぎ特化ビルドの弱体化用）：** 通貨獲得を最大化するビルドが強力になりすぎるのを防ぐため、リーフ/経験値獲得量を **パーティメンバー数で割って分配** します。
* **ポーション取得を共有：** フィールドの宝箱から出たポーションを、早い者勝ちではなく全パーティメンバーに1個ずつ付与します。
* **最大人数を拡張：** マルチプレイの人数を最大16人まで増やします。（UIが重なる場合があります。）

### 運/オブジェクト補正
* **最初の部屋に金床を保証：** 1階または2階の最初の部屋に、必ず金床を出現させます。
* **隠し部屋の通知：** マップに隠し部屋が存在する場合に知らせます。
* **尖塔の再抽選：** サイコロを1個消費して尖塔の報酬を再抽選します。
* **結束アーティファクトを許可：** 願いの泉から結束アーティファクトを獲得できるようにします。
* **図鑑の除外（Ban）機能：** ジャーナルでホイールクリックすると、アーティファクト/石板/武器/奇跡を出現しないよう除外できます。（コマンド：`/qol ban all`、`/qol ban off`）

## 難易度緩和（チート機能）

明確にゲームを簡単にするチート系オプションです。

* **マップを全て開く：** 隠し部屋と出口を含むマップ全体を即座に開示し、ファストトラベルを有効にします。
* **報酬の選択肢と宝箱を追加：** アーティファクト、インベントリ、願いの泉、フルーツ串、才能ポイント、サイコロなどの選択肢数を増やします。（ボス撃破時に宝箱倍率を適用）
* **ショップを緩和：** 商人の販売品目数と、再抽選時に追加される品目数を増やします。
* **エンチャント回数を固定：** エンチャント部屋に出現するエンチャント数を固定します。
* **ハードモード報酬の解放緩和：** ハードモード報酬の解放があまり進んでいないユーザーが高段階（60）をクリアすると、レベル50まで一度に解放されます。
* **固有制限を解除：** 固有効果を持つアーティファクトを重複して獲得し、効果を重ねられるようにします。（一部は適用不可）
* **サファイア/サイコロチート：**
  * ホストは、部屋内でゲストによる通貨チートの使用を許可するかどうかを決められます。
  * オプションを有効にすると、サファイア999,999個 / サイコロ999個に固定されます。
  * コマンド `/qol sapphire rest` でサファイアを0個にできます。

  つまり、両方の機能を使うと、

  「自分の部屋ではチート禁止」
  「自分の部屋ではチート可だが、自分は使わない」
  「自分の部屋ではチート可で、自分もチートを使う」は可能ですが、

  「自分の部屋では自分はチートを使うが、あなたは使ってはいけない」はできません。

## 画面表示

* **パーティ状況ウィンドウ：** パーティメンバーの累計ダメージ、ダメージ割合（%）、DPS、所持通貨（リーフ/サイコロ/サファイア）、コンボ TOP 3を表示します。（カスタム時は `Alt + ドラッグ` で位置を移動可能）
* **他人のピンを表示しない：** 他のプレイヤーが付けたピンのアイコンと音を即座に遮断します。
* **画面の拡大率（Zoom）：** ゲーム画面を10% ~ 200%の範囲で縮小/拡大します。
* **色覚補助モード：** ゲーム本体の設定とは別に、「インベントリの色覚補助モード」と「敵の攻撃予告の色覚補助モード」を個別に有効化できます。
  * **コマンド（敵の攻撃予告色を変更）：**
    * `/qol colorblind <r> <g> <b>`（任意のRGB値に変更）
    * `/qol colorblind reset`（デフォルトの空色にリセット）
    * `/qol colorblind`（現在適用中のRGB値を確認）
