# 塞菲莉亚 QoL (Sephiria QoL) 模组

**塞菲莉亚 QoL** 是把游戏本体不支持的各类 **便利功能、难度调整以及作弊类功能** 汇总在一起的综合模组。开发前提是单人游玩，或者 **同为 QoL 用户之间的多人游玩**。

关掉所有功能后，行为与原版（Vanilla）完全一致。

> **多人游玩注意事项**
> QoL 模组包含作弊类功能，在多人游戏中随意使用可能被视为作弊。因此在功能全开的状态下，**与原版用户的多人游玩默认受限**。
> * **自己是房主时：** 房间名会加上 `[QoL]` 前缀，原版用户进来会被自动踢出。
> * **自己是客人时：** 进入原版房主的房间后，10 秒后自动退出。
> * 想和原版用户一起玩，就用下面的 **仅便利功能** 或 **便利功能＋房主功能**，这两档不会受限。

---

## 安装方法

1. 把下载到的压缩包内容放进塞菲莉亚安装目录下的 AddOns 文件夹。
2. 路径应当是这样：
   `.../Sephiria/AddOns/SephiriaQoL/SephiriaQol.dll`
3. **注意：** `Libs` 文件夹也必须一起放在同一目录下才能正常运作！

不需要另外安装任何加载器，游戏内置的插件加载器会直接读取。

## 设置方法

游戏中按 `ESC` 打开 **暂停菜单**，可以看到多出 **[QoL 设置] · [QoL 信息] · [QoL 探索记录]** 三行。

<img width="739" height="804" alt="image" src="https://github.com/user-attachments/assets/0f6b618a-b376-4010-a474-622e3dad7902" />

设置窗口分为 `一般 / 敌人相关 / 探索相关 / 难度放宽 / 画面显示` 五个标签页，用 `Q` `E`（手柄为 LB · RB）切换。

* **滑块：** 倍率这类档位很多的行都带有滑块。
* **直接输入数值：** 带滑块的行都可以用鼠标点右侧的数值直接输入，照着屏幕上显示的写法输入即可。（`1.5` → x1.5，`150` → 150%，`2000` → +2000 树叶）
  * 倍率行也接受表里没有的值，以 0.1 为单位。按格、人、次计数的行会吸附到最近的档位。
* **开始探索后大多会隐藏：** 影响难度和奖励的行在探索开始后消失，回到大厅再出现。探索途中改难度实际上就是作弊。

## 一般设置与功能

<img width="850" height="94" alt="image" src="https://github.com/user-attachments/assets/4f18a54b-0f95-4559-b1b4-ba62daeef153" />

### QoL 功能的运行档位
按玩法习惯分为 4 档。划分依据不是难度，而是 **该功能在哪里判定**。

* **关闭（与原版相同）：** 与原版完全一致。
* **仅便利功能：** 只保留从自己的画面和自己的操作开始、也在那里结束的东西。没有任何内容会传出去，所以没有房间前缀、没有聊天提示、也没有模组握手。从外面看和没装模组的人没有区别。
* **便利功能＋房主功能：** 在上面的基础上，再加上 **只在服务器端判定** 的部分。这些功能只要房主装了模组就成立，所以对没装模组的客人同样生效。与原版用户的多人限制取消，代价是探索开始时会用聊天告知已启用 QoL 功能。
* **开启（全部）：** 启用全部功能。与原版用户的多人游玩受限。

也可以用 `/qol on | host | solo | off` 切换。只有这一项不受 `/qol reset` 和预设影响。

 <img width="850" height="59" alt="image" src="https://github.com/user-attachments/assets/479e0a73-7630-4c8c-8a60-09ca66e0f163" />

#### 「仅便利功能」下保留的选项

**〈一般〉**
* 长按连续施放魔法
* 长按连续使用特殊攻击
* 长按持续冲刺
* 持续冲刺时尽量只出冲刺攻击
* 将预设栏扩展至 100 个
* 在城镇放置天赋镜

**〈探索相关〉**
* 重抽按钮免长按
* 多人游戏人数上限（自己的上限要先放开才能进入扩容的房间，所以放在这一档。开着也不会让原版房间变宽。）

**〈画面显示〉**
* 整个标签页，包括探索记录。

不是设置行的功能（图鉴名称检索、`ESC` 菜单里的 QoL 信息）在这一档同样可用。

#### 「便利功能＋房主功能」额外保留的选项
> 以下全部 **以房主为准**。自己是房主时对没装模组的客人也生效；自己是客人时，改这些值不会影响本局探索。

**〈一般〉**
* QoL 预设

**〈敌人相关〉**
* 敌人生成 / 生命 / 伤害 / 出招速度四条倍率全部（含应用范围）
* 缓和血之盛宴
* 中型首领也套用生成倍率

**〈探索相关〉**
* 每次升级给予背包格
* 树叶 / 经验获取倍率
* 追加初始树叶、额外初始骰子
* 背包每行格数
* 首个分歧保证出现铁砧、额外铁砧
* 共享幸运徽章效果，共享谈判力 / 树叶 / 经验获取量
* 共享药水拾取
* 商人生命设置、友方同盟设置
* 商人必定出售背包格 / 经验、神秘之壶必定出现

**〈难度放宽〉**
* 固定附魔次数
* 增加铁砧选项
* 战斗中打开属性窗口／背包

被排除在外的是 **在客人机器上判定、又会改变局势的功能**：树叶与骰子转让、许愿泉相关、图鉴排除、解除唯一限制、各类作弊、尖塔重抽、重抽次数限制、游戏速度、复活速度、解除等级上限、奇迹重掷免费，以及其余的难度放宽项。只有房主开启的话，反而是没装模组的客人那边会出问题。

### 预设功能
QoL 模组可调项目很多，因此提供作者推荐的默认预设（简单／普通／困难／非常困难）。手动改动任意设置后会变成「自定义」状态。

<img width="850" height="137" alt="image" src="https://github.com/user-attachments/assets/37e9cec8-405e-4832-958e-6664d8a4099d" />

**个人预设的保存与读取（聊天指令）**
* 保存：`/qol save 1~9`
* 读取：`/qol load 1~9`
* 查看：`/qol list`

### 用一串代码交换设置
不必把设置文件整个交给对方。

* `/qol export` 把当前设置做成一行文本放进剪贴板。
* 对方复制这串代码后输入 `/qol import` 即可，也可以直接写成 `/qol import [代码]`。

导出的只有当前正在使用的那一套设置。九个存档栏不会带上，**画面显示、个人操作类选项和图鉴排除既不会被导出，也不会被覆盖。**

### 其他便利功能
* **魔法／特殊攻击自动施放：** 按住魔法或可发动神器不放，冷却结束时自动施放。（含瞬发型特殊攻击）
* **长按持续冲刺：** 按住冲刺键就会持续冲刺，而不是变成奔跑。`无限冲刺` 或冲刺攻击流派不用再连点按键。冲刺次数用完时不会做任何事，开启期间也不会触发奔跑。
* **持续冲刺时尽量只出冲刺攻击：** 只有开启上面那项时才会出现的附属选项。原本的游戏中，一边连点冲刺一边按住左键时，冲刺途中打出的是 **普通攻击** 而不是冲刺攻击。开启后，每次冲刺开始时都会再送一次左键，优先争取冲刺攻击。游戏原本的资源与冷却照常判定，因此武器无法给出冲刺攻击时仍会打出普通攻击。（弓 · 法杖 · 魔像武器不在适用范围内）
* **图鉴检索功能：** 可以在图鉴里按名称搜索条目。

<img width="584" height="81" alt="image" src="https://github.com/user-attachments/assets/7cc5a8d5-5999-4c09-9007-d86bc5fb9b58" />

* **在城镇放置天赋镜：** 在单人城镇的地下城入口前立一面天赋镜，不用再为了选天赋而反复开关多人房间。
* **查看 QoL 信息：** 在 `ESC` 暂停菜单中可以实时确认本局探索实际生效的 QoL 设置。作为客人时只显示从房主那里实际收到的值。

## 敌人相关设置

<img width="849" height="282" alt="image" src="https://github.com/user-attachments/assets/dcedbba9-b07d-41c2-991e-32e67217ba2a" />

生成、生命、伤害、出招速度四项的做法完全相同。每条倍率行下面都有一条 **应用范围**，用来决定这条倍率分得多细。

* **全局一个值：** 一个值套用到全部。
* **分层：** 第 1~6 层分别设定。
* **分敌人类型：** 普通敌人／中型首领／首领分别设定。
* **分层＋分类型：** 每层的三种类型分别设定。

各个范围的值是分开保存的，来回切换也不会被清掉。

* **敌人生成倍率：** 以倍数设定敌人的生成量，从 `1/4倍` `1/2倍` 到 `x100`。（指令：`/s 数值` 或 `/s 数值 层数`）
* **敌人生命倍率：** 调整敌人生命值。为了割草式玩法，另外提供 `按生成倍率降低` 与 `0.1倍`~`0.9倍`。（指令：`/h 数值` 或 `/h 数值 层数`）
* **敌人伤害倍率：** 从 `0.1倍` 到 `x100`，还有 `秒杀模式`。
* **敌人出招速度：** 缩短出招冷却以提高攻击频率。`0.5倍`~`3倍`。
* **中型首领的倍率套用：** 中型首领也会按生成倍率成批出现。生命方面本身数值就高，整倍套用会导致击杀时间过长，建议用分类型范围单独调低中型首领，或者选 `按生成倍率分摊`。
* **缓和血之盛宴：** 即使开着敌人生命倍率，吸血也只按怪物的「基础最大生命」计算。

`x25` 以上数值会显示为红色，套用时弹出卡顿警告。用指令最高可以指定到 999 倍。

## 探索相关设置

* **游戏速度：** 在 0.5倍~2倍 之间调整。多人游戏中 **全员统一使用房主的值。**（仅在全员都装了模组的「开启（全部）」房间生效）
* **背包每行格数：** 把默认 6 格的背包宽度改为 1~10 格。
* **蓝宝石重抽机制改动：**
  > 这个选项用来减少损害 Roguelike 本质的单纯资源重复刷取。
  > 把重抽价格固定为 0，同时为了避免无限重抽必得，可以对 **重抽次数设限**。（作弊向和限制向都能按口味调整）
* **重抽按钮免长按：** 不用按住按钮也能立刻重抽。
* **解除等级上限：** 把最高等级提升到 1000 左右，实际上取消了上限。
* **每次升级给予背包格：** 每 n 级给 1 个背包格。（用于缓解高难度探索）
* **复活速度倍率：** 多人游戏中把救起队友的速度在 0.1倍~10倍 之间调整。
* **树叶 / 经验获取倍率：** 可在 x0.1 到 x20.0 之间以 0.1 为单位调整。

### 多人游戏专属功能
* **资源转让：** 通过聊天把树叶或骰子转给他人。（可以用序号代替昵称）
  * 转让树叶：`/giveleaf [昵称/序号] [数量]`（缩写：`/gl`）
  * 转让骰子：`/givedice [昵称/序号] [数量]`（缩写：`/gd`）
* **初始物品交易：** 把许愿泉、天赋等途径获得的初始物品丢出来，让别人可以捡起。
* **幸运徽章与属性共享：**
  * 把幸运徽章的效果共享给队友。
  * 谈判力、树叶／经验获取量按队伍内最高值共享。
* **分摊功能（削弱刷钱配装）：** 为了避免把资源获取拉满的配装过强，把树叶／经验获取量 **按队伍人数分摊**。
* **共享药水拾取：** 野外箱子里开出的药水不再是先到先得，而是每位队友各得 1 个。
* **人数上限扩展：** 把多人游戏人数上限提高到 16 人。（UI 可能重叠。游戏的经验分配是按 4 人设计的，人数拉高时用经验倍率补偿更稳妥。）

### 运气／对象补正
* **首个房间保证铁砧：** 第 1 层或第 2 层的第一个房间必定生成铁砧。
* **额外铁砧：** 进入楼层时额外放置 1~2 个铁砧。
* **尖塔重抽：** 消耗 1 个骰子重抽尖塔奖励。
* **解除许愿泉限制：** 让许愿泉可以选到羁绊神器和可疑商人的商品。
* **许愿泉重复选取：** 可以放入多份同一件物品。**左键放入、右键取出**，图标左上角显示数量。容量和花费沿用游戏原本的计算，放两份花费也翻倍。独有神器最多只能放一个。（手柄上由旋转物品键负责取出）
* **图鉴排除功能：** 在图鉴中滚轮点击，把神器／石板／武器／奇迹排除出现。探索期间全员遵循房主的名单。（指令：`/qol ban all`、`/qol ban off`）

<img width="850" height="248" alt="image" src="https://github.com/user-attachments/assets/7d9891b4-a796-4fde-923f-e91feb07c15f" />

* **特殊对象保证：** 击败每层首领时强制生成尖塔、可疑商人、亚空间商店、献血事件。（第 6 层打完首领即通关，所以没有这一项。）

<img width="850" height="599" alt="image" src="https://github.com/user-attachments/assets/7cba1c05-091c-4035-aaab-5808b0694c6d" />

* **商人房设施必定出现：** 商人旁边的经验桶、背包格宝珠、神秘之壶原本各自掷骰决定去留，这些选项让它们分别必定出现。
* **商人生命设置／友方同盟设置：** 一边防止自动攻击配装误伤商人使其转为敌对，一边防止刻意击杀友方 NPC 来刷资源。商人可选 `无敌` 或 `生命设为1`，友方 NPC 可选 `从地图移除` 或 `生命设为1`。

## 难度放宽（作弊功能）

明显让游戏变简单的选项。

* **点亮整张地图：** 立即点亮包含密室和出口在内的整张地图，并启用快速移动。
* **奖励选项与箱子追加：** 增加神器、背包格、许愿泉、水果串、天赋点、初始树叶、骰子等的数量。（击败首领时套用奖励箱倍率）
* **增加铁砧选项：** 把铁砧能提供的强化全部显示出来。
* **商店放宽：** 增加商人售卖的品项数量，以及重抽时追加的品项数量。
* **固定附魔次数：** 把附魔房出现的附魔次数固定在 1~10 之间。
* **奇迹重掷免费：** 一个骰子都没有也能继续重掷奇迹。
* **战斗中打开属性窗口／背包：** 战斗进行中也能打开属性窗口和背包。时间照常流逝，所以开着窗口也会挨打。
* **启用如意宝珠刻印：** 如意宝珠原本会在死亡时复活一次，在它占据的格子上留下 `+3` 等级后消失。开启后可以对背包里的如意宝珠按住右键，填满与石板刻印相同的进度条，提前只取走后半段。留下的等级之后放在该格的神器同样适用。
* **一次性解锁困难模式奖励：** 解锁进度较少的玩家通关高段位（60）后，一次性解锁到 50 级为止的奖励。
* **解除唯一限制：** 允许重复获得带唯一效果的神器，让效果叠加。（部分神器无效）
* **蓝宝石／骰子作弊：**
  * 房主可以决定本房间内是否允许客人使用资源作弊。
  * 启用后蓝宝石固定为 999,999 个、骰子固定为 999 个。
  * 用指令 `/qol sapphire reset` 可以把蓝宝石清为 0 个。

  也就是说，用这两个功能可以做到，

  「我的房间里禁止作弊」
  「我的房间允许作弊，但我自己不用」
  「我的房间允许作弊，我自己也用」，

  但做不到「我的房间里我用作弊，你不许用」。

## 画面显示

* **队伍状况面板：** 显示队友的累计伤害、伤害占比(%)、DPS、持有资源（树叶／骰子／蓝宝石）以及连携 TOP 3。各项可以单独开关，位置可选 `右侧` 或 `自定义`（用 `Alt + 拖拽` 移动）。
* **画面缩放：** 把游戏画面在 10%~200% 之间缩小或放大。
* **色盲模式：** 与游戏本体设置分开，可单独启用「背包色盲模式」和「敌人攻击预告色盲模式」。
  * **指令（更改敌人攻击预告颜色）：**
    * `/qol colorblind <r> <g> <b>`（改成想要的 RGB 值）
    * `/qol colorblind reset`（恢复默认天蓝色）
    * `/qol colorblind`（查看当前的 RGB 值）
* **掉落的经验与树叶：** 把地上掉落的经验和树叶画得更淡（50% ／ 25% ／ 不显示）。画面繁忙时它们容易和敌人弹幕混淆，这里只改变绘制方式，不影响拾取。
* **显示首领生命数值：** 在首领和中型首领的血条上标出数值。
* **显示首领的仇恨目标：** 给首领和被盯上的一方画上同色描边。
* **在背包格显示附魔次数：** 在物品格右下角写上 `★2` 之类的附魔次数。原本需要逐格悬停看提示才知道。（默认开启）
* **存在密室时提示：** 地图上有密室时，进入该层时用一行提示告知。
* **隐藏他人的标记：** 立即屏蔽其他玩家打出的标记图标和音效。
* **启用聊天记录：** 打开聊天框后把鼠标放到记录上滚动滚轮，可以回看最近 200 行。
* **高亮物品获得提示：** 把获得记录里的物品名按稀有度着色。当场凑成羁绊的神器则用金色到绿色的渐变单独标出。

### 探索记录
游戏没有提供回看已结束探索的手段，结算画面一关，那局的背包和伤害数据就全没了。因此在结算画面打开的瞬间，把 **最近 30 局** 写入文件。

用 `ESC` → `QoL 探索记录` 或 `/qol runs` 查看。可在 `关闭 ／ 仅自己 ／ 队伍全员` 中选择，默认是 `仅自己`。

* 每条记录保留结果、最后所在位置、游玩时长、等级、武器、奇迹、造成／承受的伤害以及主要伤害来源。
* 按 `Tab` 切到 **背包** 页，可以看到那局结束时背包的原样布局；再按一次是 **统计** 页。
* 按 `Enter` 会重新打开 **游戏本身的结算画面**，从那里再点 `[伤害]` 就能看到那局的伤害窗口。
* 操作：键盘 `← →` 切局、`↑ ↓` 切人、`Tab` 换页、`Enter` 详情、`ESC` 关闭；手柄使用方向键、`Y`、`A`、`B`。
* 记录只写在自己机器上的一个文件里，不进行任何通信。可以用 `/qol runs clear` 清除。（无法撤销）

## 聊天指令

```
/help                              指令说明

/s <倍率> [层]                     敌人生成倍率   (/spawnrate)
/h <倍率> [层]                     敌人生命倍率   (/hprate)

/gl <名字|序号> <数量>              转让树叶      (/giveleaf)
/gd <名字|序号> <数量>              转让骰子      (/givedice)
/cheat s | /cheat d                查看蓝宝石 · 骰子作弊状态

/qol on | host | solo | off        全部 / 便利+房主 / 仅便利 / 关闭
/qol reset                         把所有设置恢复成原版
/qol load easy|normal|hard|expert  套用难度预设
/qol save <1~9> | load <1~9>       存入 / 读取存档栏
/qol list                          查看预设与存档栏状态
/qol export | import [代码]         用代码交换设置
/qol ban all | off                 排除 / 恢复全部神器
/qol runs [clear]                  查看 / 清除探索记录
/qol speed                         查看当前生效的游戏速度及来源
/qol sapphire reset                把蓝宝石清为 0 个
/qol colorblind <r> <g> <b>        设定攻击预告的强调色
```

倍率指令后面写上层数就会自动切换到分层设置，不写层数则使用全局值。只输入指令而不带数值时，会显示当前设置。

修改设置的指令 **只能在大厅使用**。只读的 `/qol list` `/qol export` `/qol runs` `/qol speed` 在探索中也能用。
